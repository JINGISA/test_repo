# ASCII 영상 만들기

이 저장소에는 numpy로 장면을 계산해 ASCII 문자로 찍어내는 `asciiscene` 패키지가 있다.
사용자가 영상을 요청하면 **바로 코드를 짜지 말고, 아래 질문부터 한다.**

## 1. 먼저 물어볼 것

사용자가 이미 말한 항목은 다시 묻지 않는다. 빠진 것만 AskUserQuestion으로 한 번에 묻는다
(한 번에 최대 4문항이므로 중요한 것부터, 나머지는 기본값을 쓰고 결과 보고에서 알린다).

| 항목 | 물어볼 내용 | 기본값 |
|---|---|---|
| 장면 | 무엇을 그릴지. 기존 장면(`python render.py --help`의 목록)인지 새 장면인지 | 없음, 반드시 확인 |
| 분위기·색 | 주 색상, 밝기, 차분한지 역동적인지. 참고 이미지나 영상이 있으면 받는다 | 장면 기본값 |
| 화면 방향 | 가로(1920x1080, 유튜브) / 세로(1080x1920, 릴스·쇼츠) / 정사각(1080x1080) | 가로 |
| 길이 | 몇 초인지 | 12초 |
| 글자 크기 | 고운 질감(5x8) / 글자가 또렷이 보이는 굵은 질감(8x12 이상) | 5x8 |
| 넣고 뺄 요소 | 별, 나무, 호수 반사, 분홍 가장자리 등 장면별 요소 | 전부 포함 |

새 장면이라면 추가로 묻는다: 화면 구성(무엇이 어디에 있는지), 무엇이 어떻게 움직이는지.

## 2. 만드는 방법

기존 장면이면 코드를 고치지 않고 매개변수만 바꾼다.

```
python render.py aurora --params                      # 바꿀 수 있는 값 목록
python render.py aurora --png 경로.png --time 3       # 정지 화면 한 장 (빠른 확인용)
python render.py aurora --out 경로.mp4 --size 1080x1920 --seconds 15 --set pink=0 --set horizon=0.6
```

새 장면이면 `asciiscene/scenes/<이름>.py`를 만든다.

- `Scene`을 상속하고, `PARAMS`에 조절 가능한 기본값을, `setup()`에 프레임마다 변하지 않는 계산을,
  `image(t)`에 시간 `t`의 색상 배열 `(rows, cols, 3)`(0~1 float) 반환을 넣는다.
- `asciiscene/scenes/__init__.py`의 `SCENES`에 등록한다.
- `asciiscene/noise.py`(노이즈)와 `asciiscene/layers.py`(`Stars`, `Treeline`, `FrozenLake`,
  `gradient`, `tone_map`)를 먼저 재사용한다. 다른 장면에도 쓸 만한 조각은 `layers.py`에 추가한다.
- 픽셀별 파이썬 반복문은 쓰지 않는다. 전부 numpy 배열 연산으로 계산해야 속도가 나온다.
- ASCII 변환·영상 저장 코드(`ascii.py`, `output.py`)는 장면 때문에 고칠 일이 없어야 한다.
- 참고 구현은 `asciiscene/scenes/aurora.py`.

## 3. 확인하며 다듬기

1. `--png`로 서로 다른 시점 두 장(예: `--time 3`, `--time 9`)을 뽑아 직접 열어 본다.
2. 요청한 장면처럼 보이지 않으면 숫자를 고치고 다시 뽑는다. 영상 렌더는 정지 화면이 괜찮아진 뒤에 한다.
3. 영상을 렌더한 뒤 길이와 해상도를 `ffprobe`로 확인한다.

산출물(png, mp4)은 저장소에 커밋하지 않는다. 임시 폴더에 만들어 사용자에게 파일로 보낸다.

## 4. 결과 보고

영상 파일을 보내고, 다음을 짧게 알린다: 쓴 설정(크기, 길이, 바꾼 매개변수), 질문 없이 기본값으로
정한 항목, 요청과 다르게 나온 부분. 그 다음 고치고 싶은 점을 묻는다.
